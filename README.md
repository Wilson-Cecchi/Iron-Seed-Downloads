# Iron Seed — downloads

Este repositório publica versões de teste do Iron Seed para Windows x64. O
código-fonte do jogo permanece privado.

[Baixar a versão mais recente para Windows x64](https://github.com/Wilson-Cecchi/Iron-Seed-Downloads/releases/latest/download/IronSeed-Windows-x64.zip)

Extraia o ZIP por completo e execute `gdp.exe` na pasta `GDP-Windows-x64`.
Mantenha `SDL3.dll` e a pasta `ai` ao lado do executável. O pacote ainda não
possui assinatura digital e exige Windows x64 com suporte a OpenGL 3.3.

O endereço de download acima permanece o mesmo; ele muda de conteúdo apenas
quando uma nova Release é publicada. Estas são compilações de teste, não uma
versão final do jogo.
